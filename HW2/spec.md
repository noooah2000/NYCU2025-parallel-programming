# Multi-thread Programming

## Overview

This assignment focuses on shared-memory parallelization using threads. Students explore synchronization, data partitioning, and performance tuning for multi-threaded workloads.

## Reference

- Course specification: https://nycu-sslab.github.io/PP-f20/HW2/

## Learning Goals

- Understand the parallel programming model used in this assignment.
- Implement the required algorithm or workload.
- Measure and compare the performance of different execution strategies.
- Validate correctness using provided test inputs or reference outputs.

## Notes

- Use the source files in this folder as the working implementation.
- Keep generated binaries and large temporary outputs out of version control.
